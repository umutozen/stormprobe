# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security vulnerabilities by emailing:

**umutozen [at] proton [dot] me**

Include the following in your report:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within 72 hours. If the issue is confirmed, a patch
will be released as soon as possible.

## Scope

StormProbe is a load testing tool. By design it generates high volumes of HTTP
requests. Use it only against systems you own or have explicit written permission
to test. Misuse may violate applicable laws.

## Disclosure Policy

We follow [Responsible Disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure).
Once a fix is available, we will publish a security advisory on GitHub.
